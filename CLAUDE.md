# Instrucciones para Claude

Lee primero [`HANDOFF.md`](./HANDOFF.md). Contiene el contexto completo de Minka Web, los dominios, las decisiones de producto, integraciones, comandos de verificación y el proceso de publicación.

Reglas rápidas:

- No expongas tokens, claves ni variables de entorno en el repositorio.
- No reintroduzcas planes ni precios fijos: la propuesta comercial es personalizada.
- Ejecuta `npm run lint` y `npm run build` antes de publicar.
- Prueba el menú hamburguesa en móvil después de cambios al header o CSS.
- Haz commits pequeños y claros; publica únicamente cambios verificados a `main`.
